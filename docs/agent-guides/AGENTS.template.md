## 9. Безопасность

Никогда не коммить secrets, `.env`, tokens, private keys, cookies, реальные данные, дампы и локальные runtime-каталоги.

Обязательно учитывать:

- server-side authorization;
- least privilege;
- tenant/project isolation;
- input validation;
- secret redaction;
- webhook signature/replay, если применимо;
- path traversal и unsafe content, если есть файлы;
- audit/approval для чувствительных автоматических действий.

Если обнаружен секрет, остановись и сообщи путь/тип риска без публикации значения.

# I1.4 — Внешние источники знаний

## Пользовательский результат

Команда подключает разрешённый внешний источник к project, видит sync/index state и использует его в Project Brain без ручного копирования файлов.

## Зависимости

- I1.2;
- выбран один connector и разрешены credentials/data handling;
- generic source adapter contract стабилен.

## Scope

- connector registry;
- connection secret reference;
- source discovery/selection;
- incremental sync cursor/webhook if available;
- normalized provenance;
- revoke/delete behavior;
- status/error UI;
- первый конкретный connector.

## Не входит

- несколько connectors одновременно;
- запись во внешнюю систему;
- обход provider permissions;
- неограниченный crawling URL/web.

## Порядок реализации

1. Выбрать один provider по реальной потребности.
2. Описать scopes/data retention.
3. Реализовать connector adapter.
4. Добавить safe auth/secret storage.
5. Реализовать source selection.
6. Sync metadata/content с versions.
7. Ingest через existing pipeline.
8. Revoke немедленно исключает retrieval.
9. Добавить reconciliation/retry.
10. Прогнать provider sandbox fixtures.

## Критерии приёмки

1. Пользователь выбирает конкретные sources/folders.
2. Provider ACL не расширяется.
3. Incremental sync идемпотентен.
4. Citation ведёт к canonical external source.
5. Revoke прекращает sync и retrieval.
6. Token не доступен browser/log.
7. Provider outage не ломает local sources.

## Rollback

Отключить/revoke connector. Cached derived chunks исключаются; canonical external source остаётся у provider.

# I0.6 — Проекция Plane Work Item на Canvas

## Пользовательский результат

Пользователь добавляет существующую задачу Plane на Canvas, видит актуальные поля, быстро меняет разрешённые значения и может создать новую задачу из Canvas без второй таблицы тикетов.

## Зависимости

- I0.5;
- границы/Canvas/API документы 03/06/07.

## Scope

- bindings model/migration/API;
- project-scoped search Work Items;
- `work_item_ref` node;
- live title/state/priority/assignee/due date;
- quick edit allowlist через Plane service/API;
- create Work Item from Canvas;
- open canonical Work Item;
- deleted/archived state;
- remove projection semantics;
- cross-project tests.

## Не входит

- собственный Kanban/backlog;
- comments;
- cycles/modules projection;
- delete Work Item from Canvas;
- realtime events beyond practical refresh/invalidation.

## Порядок реализации

1. Добавить binding schema/constraints.
2. Реализовать source resolver с project check.
3. Реализовать search endpoint с pagination.
4. Создать node renderer/loading/stale/deleted states.
5. Добавить binding при создании shape transactionally или с компенсирующим rollback.
6. Реализовать quick edit с source version/precondition.
7. Реализовать create Work Item через штатный Plane service.
8. Разделить `Убрать с холста` и source actions.
9. Добавить refresh после edit вне Canvas.
10. Проверить два shapes одного Work Item.

## Критерии приёмки

1. Work Item текущего project добавляется на Canvas.
2. Foreign Work Item binding отклоняется.
3. Изменение status отражается в разделе «Работа».
4. Work Item, созданный на Canvas, существует в Plane и имеет binding.
5. Нет PPM tickets table.
6. Удаление shape не удаляет Work Item.
7. Один Work Item может иметь несколько projections.
8. Удалённый source показывает понятный state.

## Проверки

- binding constraints;
- permission/cross-project matrix;
- quick edit integration;
- create idempotency;
- delete projection safety;
- external update refresh;
- E2–E4;
- baseline board/list regression.

## Rollback

Скрыть node type и bridge flag. Bindings остаются безопасными metadata; Plane Work Items не изменяются при rollback.

## Stop rules

- предлагается хранить копию title/state как canonical;
- mutation обходит Plane permission/service;
- shape delete вызывает source delete;
- cross-project source resolver не закрыт тестом.

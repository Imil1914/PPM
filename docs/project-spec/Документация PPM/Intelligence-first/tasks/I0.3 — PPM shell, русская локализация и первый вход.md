# I0.3 — PPM shell, русская локализация и первый вход

## Пользовательский результат

Пользователь регистрируется и работает в собственной оболочке PPM. На главном пути отсутствует визуальная идентичность Plane, русский язык включён по умолчанию, сохраняется один login.

## Зависимости

- I0.2;
- навигация и термины из документов 02/11/18.

## Scope

- auth/invitation/workspace/project first path;
- default locale `ru` для нового пользователя с возможностью `en`;
- PPM global/project shell;
- новая project navigation;
- routes-placeholder `Мозг проекта`, `Знания`, `Код` с feature states;
- PPM empty/loading/error states основного пути;
- command palette/nav accessibility;
- link `Открытый исходный код`;
- user-facing brand audit allowlist.

## Не входит

- полная перерисовка settings/admin/emails;
- реализация Canvas/Vault/Git content;
- изменение Plane auth model.

## Порядок реализации

1. Зафиксировать E1 screenshots baseline.
2. Определить route map без изменения canonical project IDs.
3. Создать shell wrapper/layout.
4. Подключить русские labels через i18n keys.
5. Настроить default locale only for users without saved language.
6. Переработать auth/onboarding/project create surfaces.
7. Добавить navigation и feature placeholders.
8. Проверить deep links и browser refresh.
9. Проверить viewer/member/admin variants.
10. Выполнить automated brand scan + visual E1.

## Критерии приёмки

1. Нет второго login/token store.
2. Новый пользователь по умолчанию видит русский UI.
3. Смена языка сохраняется.
4. Основная navigation соответствует документу 02.
5. Auth, home, project, Work Items не показывают Plane brand вне legal allowlist.
6. Direct link/reload не теряет context.
7. Отключённые функции объясняют следующий этап, а не падают.
8. Штатный Work Item flow работает.

## Проверки

- auth/project E2E;
- locale persistence;
- navigation capability tests;
- visual Graphite/Light;
- keyboard/focus;
- brand string/assets scan;
- Plane baseline regression.

## Rollback

Feature flag shell/brand возвращает baseline routes. Auth/data migrations отсутствуют либо additive.

## Stop rules

- требуется новый auth;
- route rewrite ломает existing links;
- brand removal затрагивает mandatory legal notice;
- translation меняет API/internal identifiers.

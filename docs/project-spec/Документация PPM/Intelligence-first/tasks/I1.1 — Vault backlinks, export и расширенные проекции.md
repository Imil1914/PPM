# I1.1 — Vault backlinks, export и расширенные проекции

## Пользовательский результат

Project Vault работает как переносимая база знаний: wiki-links, backlinks, graph, versions/trash/export; Canvas поддерживает Plane Page, attachment и Vault file projections.

## Зависимости

- I0.10 accepted;
- документы 07/09/16.

## Scope

- parse/resolve wiki-links;
- backlinks/graph API/UI;
- rename/move alias/update policy;
- versions/restore/trash;
- ZIP export manifest;
- Page/attachment/vault projections;
- previews/locators;
- explicit Page↔Markdown import/export provenance;
- expanded file type storage allowlist.

## Не входит

- automatic bidirectional Page sync;
- WebDAV/offline sync;
- office collaborative editing;
- OCR unless separate task approved.

## Порядок реализации

1. Добавить vault link model/migration.
2. Реализовать parser fixtures и resolver states.
3. Reindex links on Markdown version.
4. Реализовать rename/move stable ID behavior.
5. Добавить backlinks/graph UI.
6. Реализовать versions/restore/trash.
7. Реализовать deterministic export manifest/ZIP safeguards.
8. Добавить projection resolvers/renderers.
9. Реализовать explicit import/export provenance.
10. Выполнить Obsidian-open manual test exported folder.

## Критерии приёмки

1. Wiki-link даёт backlink/graph edge.
2. Rename/move не меняет entry ID и не теряет link.
3. Restore создаёт новую current version.
4. Export содержит обычную папочную структуру и `.md`.
5. ZIP безопасен и имеет manifest.
6. Page/file projections открывают canonical sources.
7. Удаление projection/source строго разделено.
8. Cross-project links не раскрывают source.

## Проверки

- parser/resolver ambiguity;
- rename/move/version conflicts;
- export traversal/symlink/large cases;
- projection permissions;
- Obsidian/manual Markdown readability;
- graph performance smoke;
- regression E5/E6.

## Rollback

Выключить expanded Vault features/node types. Canonical versions/links не удаляются.

# I0.4 — Web Canvas route и browser-safe AntyFlow core

## Пользовательский результат

Внутри PPM project открывается «Мозг проекта» с AntyFlow/tldraw холстом и локальной note-нoded, используя текущую Plane session и project context.

## Зависимости

- I0.3;
- [../07 — Холст и проекции сущностей](<../07 — Холст и проекции сущностей.md>).

## Scope

- project route;
- browser-safe Canvas package;
- tldraw integration;
- PPM theme;
- node registry;
- `note` и `group`;
- typed visual arrows без semantic persistence;
- loading/empty/error/deny;
- feature flag;
- temporary in-memory/local test store only до I0.5, явно обозначенный.

## Не входит

- server persistence;
- Work Item projection;
- Vault/RAG;
- realtime;
- Electron-only nodes.

## Порядок реализации

1. Инвентаризировать переносимые AntyFlow imports.
2. Создать dependency boundary/test, запрещающий Electron/Node imports.
3. Подключить tldraw совместимой закреплённой версии; при version conflict зафиксировать решение.
4. Создать minimal Canvas shell/toolbar.
5. Реализовать versioned node schema для note/group.
6. Перенести визуальные tokens/motion с reduced-motion.
7. Получить workspace/project context из route/session.
8. Проверить permission read route.
9. Добавить corrupt/unknown node fallback.
10. Выполнить build и manual pan/zoom/create/link.

## Критерии приёмки

1. Route доступен из project navigation.
2. Project context не выбирается повторно.
3. Unauthenticated/outsider получает deny.
4. Note/group создаются и редактируются в текущей сессии.
5. Unknown/corrupt node не роняет Canvas.
6. Web bundle не содержит Electron IPC, `fs`, `better-sqlite3`, webview/terminal/kernel.
7. Остальные project routes работают.

## Проверки

- dependency/import guard;
- node schema/migration unit tests;
- route permission test;
- production web build;
- visual/accessibility smoke;
- project navigation regression.

## Rollback

Выключить `PPM_CANVAS_ENABLED`; route скрывается без изменения Plane data.

## Stop rules

- несовместимость tldraw требует случайного major upgrade;
- перенос требует Electron API;
- доступ проверяется только frontend;
- Canvas ломает global routing/build.

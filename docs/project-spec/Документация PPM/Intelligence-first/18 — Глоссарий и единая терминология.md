# 18 — Глоссарий и единая терминология

| Термин | Значение | Не путать |
|---|---|---|
| PPM | весь продукт проектной школы | не только Canvas |
| AntyFlow | исходный desktop-прототип и дизайн/interaction foundation | не отдельный логин в web |
| Plane Engine | внутренний fork Plane Community | не пользовательский бренд |
| Пространство | workspace Plane в UI PPM | не Project Vault |
| Проект | Plane project и общий security scope | не Canvas room |
| Задача | Plane Work Item | не самостоятельная Canvas card |
| Этап | UI-название Cycle | не timeline-полоса Canvas |
| Направление | UI-название Module | не Canvas group без binding |
| Мозг проекта | Canvas + graph + ask/agent experience | не только vector DB |
| Canvas/Холст | пространственное представление проекта | не Kanban Plane |
| Проекция | shape-ссылка на canonical entity | не копия сущности |
| Project Vault | папки, Markdown и файлы проекта | не Plane attachment store |
| Plane Page | collaborative rich-text page | не Vault `.md` автоматически |
| Вложение | файл, прикреплённый к Plane entity | не библиотечный Vault file |
| Wiki-link | `[[...]]` ссылка между Vault notes | не Canvas semantic edge |
| Semantic edge | типизированная связь двух Canvas nodes | не просто линия |
| Project Brain | ingestion, index, retrieval, memory и agents | не отдельная foundation model |
| Embedding model | модель преобразования текста в vector | не база знаний |
| Project index | изолированный набор chunks/vectors одного project | не отдельная обученная модель |
| Hybrid RAG | keyword + vector retrieval с источниками | не обычный LLM chat |
| GraphRAG | retrieval с учётом typed edges | не только Vault graph view |
| Citation | ссылка ответа на точный source/locator/version | не декоративный URL |
| Agent run | один отслеживаемый запуск агента | не диалог целиком |
| Agent action | типизированное предложение mutation | не свободный текст |
| Git provider | GitHub/GitLab/Forgejo, владелец Git data | не PPM API |
| Repository link | связь project с repository | не копия repository в PPM |
| Pull request | объект Git provider | не Work Item |
| Source of truth | единственное место авторитетной записи объекта | не cache/index |
| Derived data | данные, полностью восстанавливаемые из sources | не backup canonical data |

## Русские команды интерфейса

- `Спросить проект` — query Project Brain;
- `Добавить на холст` — создать projection;
- `Открыть источник` — перейти к canonical entity;
- `Убрать с холста` — удалить projection, не source;
- `Индексировать` — разрешить ingestion source;
- `Исключить из индекса` — немедленно запретить retrieval;
- `Предложенные действия` — agent actions до approve;
- `Применить выбранные` — approve выбранных actions.

## Запрещённые неоднозначные формулировки

- «скопировать задачу на холст» → `добавить проекцию задачи`;
- «загрузить в AI» → `проиндексировать в Project Brain`;
- «своя модель проекта» → `свой индекс и настройки модели`;
- «удалить карточку» без уточнения → `убрать projection` либо `удалить Work Item`;
- «встроить GitHub целиком» → указать provider adapter или bundled Forgejo;
- «хранилище Plane» без типа → Page, attachment либо Vault file.

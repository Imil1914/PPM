# 06 — Приёмка и тестовая стратегия

## Definition of Done Plane baseline

- версия Plane закреплена точным tag/commit;
- полный исходный код и лицензия доступны;
- официальный stack запускается воспроизводимо;
- пользователь регистрируется;
- workspace/project/work item/page работают;
- restart не теряет данные;
- baseline зафиксирован до PPM-патчей.

## Сквозные сценарии

### A1. Первый вход

Пользователь регистрируется один раз и после onboarding видит интерфейс Plane, а не отдельный PPM dashboard.

### A2. Штатный Plane

Пользователь создаёт project, work item, cycle/module по доступному функционалу версии и Page. PPM-патчи не ломают штатные views.

### A3. Холст project

Из project navigation пользователь открывает «Холст». URL и API привязаны к текущим workspace/project.

### A4. Сохранение

Пользователь создаёт две ноды и связь. После reload и restart snapshot восстановлен.

### A5. Общий project

Второй участник того же project видит холст. Посторонний пользователь получает deny по UI и прямому API.

### A6. Work-item bridge

Созданный в Plane work item появляется для добавления на холст. Созданный из холста work item появляется в штатном списке Plane.

### A7. Безопасное удаление

Удаление work-item shape с холста не удаляет work item. Архивированный work item отображается как недоступный/архивный binding.

### A8. Единая поставка

Plane и Canvas открываются на одном HTTPS-домене без второго логина.

### A9. Лицензия

Пользователь может открыть legal notice и получить соответствующий source code используемой модифицированной версии Plane.

## Автоматические проверки

- upstream Plane baseline tests согласно репозиторию;
- build затронутых Plane apps/packages;
- Canvas typecheck/unit tests;
- Canvas API permission tests;
- create/read/update/conflict snapshot tests;
- Plane work-item API integration;
- E2E `register → project → work item → canvas → reload`;
- license/source-link check;
- compose configuration validation.

## Negative matrix

| Сценарий | Ожидание |
|---|---|
| unauthenticated canvas request | deny |
| member другого workspace | deny |
| member без project access | deny |
| viewer update canvas | deny |
| stale canvas version | conflict, без перезаписи |
| invalid shape binding | validation error |
| Plane API unavailable | canvas остаётся доступен, bridge показывает ошибку |

## Release gate PF0.7

1. A1–A9 пройдены.
2. Нет P0/P1 по auth, доступу или потере данных.
3. Plane baseline не имеет новых регрессий от PPM patches.
4. Полный source link и AGPL notice доступны.
5. Известные ограничения опубликованы.
6. Есть backup/restore и rollback на предыдущий pin.
7. Владелец вручную принимает демонстрацию.

# P0.3 — Команды и проекты

## Цель

Дать владельцу и руководителю возможность создавать команды, управлять составом и заводить проекты.

## Зависимости

P0.2 в `review`.

## Scope

- `teams`, `team_members`, `projects`;
- роли owner/lead/member/viewer;
- список команд и состав;
- создание проекта с ключом;
- поле внешнего `repo_url`;
- создание стандартной доски и колонок в транзакции;
- RLS для team/project.

## Критерии приёмки

1. Владелец создаёт команду.
2. Руководитель создаёт проект своей команды.
3. Участник не может создать проект.
4. Outsider не открывает команду или проект по прямому URL.
5. Ключ проекта уникален внутри workspace.
6. Повторный запрос не создаёт вторую стандартную доску.

## Проверки

- contract/unit tests;
- RLS matrix;
- integration `create team → project → default board`;
- seed 20 команд и загрузка списка.

## Не входит

Portfolio analytics, публичные проекты, несколько досок на проект и Git API.

## Gate

Эталонная команда и проект ROBOT создаются через UI.

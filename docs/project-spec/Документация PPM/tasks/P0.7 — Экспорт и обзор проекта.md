# P0.7 — Экспорт и обзор проекта

## Цель

Дать руководителю переносимый снимок состояния проекта без ручного копирования.

## Зависимости

P0.4 и P0.5 в `review`.

## Scope

- counters по категориям статуса;
- CSV тикетов;
- Markdown-сводка проекта;
- UTF-8 и русские заголовки;
- фильтр проекта и доступ пользователя;
- корректные имена файлов.

## Критерии приёмки

1. CSV открывается и содержит номер, название, статус, приоритет, исполнителя и срок.
2. Markdown содержит цель, прогресс, активные работы и блокировки.
3. Экспорт включает только доступный проект.
4. Поля экранированы от поломки CSV.
5. Outsider получает отказ, а не пустой экспорт.

## Проверки

- snapshot структуры CSV/Markdown;
- кавычки, переносы строк, кириллица;
- RLS/API deny;
- пустой проект и 100 тикетов.

## Не входит

XLSX, PDF, презентации, custom report builder и экспорт всех файлов одним архивом.

## Gate

Экспорт эталонного ROBOT соответствует данным на доске.

# Очередь карточек PPM

> Очередь P0.1–P0.8 отменена до начала реализации. Актуальная очередь: [../Intelligence-first/tasks/README](<../Intelligence-first/tasks/README.md>).

## Правила

- Одна карточка — один проверяемый результат.
- Одновременно выполняется одна карточка критического пути.
- Следующая карточка становится `ready` после перевода зависимости в `review` и прохождения её gate.
- `accepted` ставит только владелец после демонстрации.
- Git-контур не запускается до P0.8.

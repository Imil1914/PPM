# P0.6 — Агенты с подтверждением

## Цель

Подключить Project Reporter и Ticket Decomposer с ограниченным контекстом, preview и идемпотентным approve.

## Зависимости

P0.4 и P0.5 в `review`; есть разрешённый LLM provider или mock runtime.

## Scope

- `agent_runs`, `agent_actions`;
- Zod-контракты входа/выхода;
- Project Reporter;
- Ticket Decomposer;
- список источников;
- preview, approve, reject, retry;
- audit event;
- mock runtime для тестов.

## Критерии приёмки

1. Agent context ограничен одним проектом.
2. Ответ ссылается только на переданные тикеты/документы.
3. До approve изменения не появляются.
4. Повторный approve идемпотентен.
5. Невалидный model output не применяется.
6. При отсутствии LLM ручной PPM работает.

## Проверки

- deterministic mock tests;
- invalid JSON/schema output;
- outsider context deny;
- approve/reject/retry;
- provider timeout and error.

## Не входит

Автономные циклы, фоновые cron-агенты, Git review, RAG по бинарным файлам и массовые действия без подтверждения.

## Gate

Project Reporter создаёт проверяемый draft, Ticket Decomposer — 3–10 draft actions.

# P0.1 — Web foundation и preview deploy

## Цель

Создать минимальный web-каркас PPM, который собирается локально и открывается по публичному preview URL.

## Зависимости

- Определить каталог нового приложения: рекомендуется `apps/ppm-web` в репозитории AntyFlow или отдельный репозиторий PPM.
- Не подключать реальные данные до подтверждения архитектурного решения.

## Scope

- Next.js + TypeScript;
- страницы `/`, `/login`, `/app`;
- общий layout и навигация-заглушка;
- схема переменных окружения без секретов;
- health endpoint/page;
- lint, typecheck, production build;
- preview deploy.

## Критерии приёмки

1. Чистая установка зависимостей воспроизводима.
2. `build` проходит.
3. `/` объясняет, что PPM — demo MVP.
4. `/app` доступен как каркас и не содержит mock-секретов.
5. Публичный preview работает по HTTPS.
6. В репозитории есть `.env.example`, но нет реальных ключей.

## Проверки

- lint;
- typecheck;
- production build;
- открыть `/`, `/login`, `/app`, health в чистом браузере.

## Не входит

Auth, БД, команды, тикеты, перенос tldraw и Electron IPC.

## Gate

Preview стабилен; P0.2 может подключать backend без перестройки каркаса.

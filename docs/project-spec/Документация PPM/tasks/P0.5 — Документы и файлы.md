# P0.5 — Документы и файлы

## Цель

Создать простое проектное хранилище: Markdown-документы и приватные файлы, связанные с тикетами.

## Зависимости

P0.3 в `review`.

## Scope

- `documents`, `document_links`, `files`;
- список и редактор Markdown;
- preview;
- привязка документа к тикету;
- private Storage bucket;
- upload/download через проверенный путь;
- тип, размер, автор и время загрузки;
- безопасное архивирование metadata.

## Критерии приёмки

1. Документ сохраняется после reload.
2. Документ связывается только с тикетом того же проекта.
3. Файл загружается и скачивается членом команды.
4. Outsider не получает файл даже зная storage path.
5. Файл выше лимита и запрещённый тип обрабатываются без частичной записи.
6. Storage key не содержит исходный путь пользователя.

## Проверки

- document CRUD;
- cross-project link deny;
- storage allow/deny;
- допустимый файл, oversized файл, повторное имя;
- production build.

## Не входит

Совместное редактирование, история версий, backlinks-граф, OCR, RAG и онлайн-редактирование Office.

## Gate

Эталонный «Журнал испытаний» и CSV доступны только команде ROBOT.

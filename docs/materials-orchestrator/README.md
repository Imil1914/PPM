# Материаловедческий оркестратор AntyFlow

Эта папка — канонический источник архитектуры и исполнительного ТЗ профиля `materials_rnd`.

> Важно: документы `01–02` описывают целевую архитектуру. Документы `03–10` превращают её в проверяемый план расширения существующего кода. Этапы M0.1–M1.3 реализованы и приняты; неизменяемый Version Repository M1.4 реализован и находится на ревью. Полноценный доменный materials engine ещё не создан.

## Рекомендуемый порядок чтения

- Для общего понимания: `01 → 02 → 03`.
- Для проектирования реализации: `03 → 04 → 05 → 06`.
- Для разработки и проверки: `06 → 07 → 08 → 09 → 10`.
- Для одной задачи Codex: карточка задачи и только перечисленные в ней разделы.

## Зафиксированные границы

- Пилотный объект: термостойкая алюминиевая конструкционная пластина.
- Скрининговый режим: 200 °C, выдержка 100 часов, кратковременный пик 250 °C.
- Система сравнивает несколько связок «состав + маршрут + термообработка».
- Система предлагает и ранжирует варианты; инженер редактирует и утверждает.
- Выход — цифровой `ExperimentPackageV1` и связанные артефакты.
- AntyFlow не управляет лабораторией, оборудованием или 3D-принтером.
- Физические результаты могут быть возвращены только ручным импортом в следующую итерацию.

## Правило синхронизации

Каноническая версия хранится в репозитории. Точная копия публикуется в Obsidian в папке:

`10 Проекты/AntyFlow/Материаловедческий оркестратор`

При расхождении источником истины считается версия из репозитория.

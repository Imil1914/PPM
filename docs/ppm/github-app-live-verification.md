# Живая проверка Git-интеграции PPM

Дата: 2026-09-21  
Карточки плана: G1.1, G1.2

Этот небольшой документ создан в отдельной проверочной ветке, чтобы пройти безопасный сценарий:

1. создать ветку от `main`;
2. записать коммит;
3. открыть черновой pull request;
4. дождаться, пока PPM получит новые branch, commit и PR через фоновую синхронизацию;
5. проверить связь Git-сущностей с проектом и их отображение в разделе «Код».

Проверка не изменяет рабочую ветку разработки и не сливается в `main` автоматически. После проверки владелец репозитория сможет закрыть PR либо принять его обычным способом.

## Ожидаемый результат в PPM

- новая ветка видна в подключённом репозитории;
- коммит отображается с канонической ссылкой на GitHub;
- черновой PR отображается один раз без дубликатов;
- ручная синхронизация и периодическое восстановление дают одинаковое состояние;
- состояние Git-подключения остаётся понятным пользователю.
